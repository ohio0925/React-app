#FastAPI起動(main.py)
1.ターミナルでcd backendで階層に映る
2.以下コマンド実行
uvicorn main:app --reload

#フロント起動
1.ターミナルでcd frontendで階層に移る
2.以下コマンド実行
npm run dev
3.ブラウザにアクセス
http://localhost:3000

#一括インストール
pip install -r requirements.txt
下記を一括でインストールできる
fastapi
uvicorn
sqlalchemy

#一括起動
cd frontend
npm run dev:full

#sql確認
1．vscode上の入力欄から>Sqlite: OpenDatabaseを入力
2.確認したいテーブルを選択
3.左下のsqlite explorerを選択
4.showdatabaseを押下
